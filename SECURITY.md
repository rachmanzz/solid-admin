# Security Policy

## Supported versions

This project is an admin UI template and is not yet released as a versioned,
production software package. We currently provide security updates only for the
latest state of the `main` branch.

## Reporting a vulnerability

If you discover a security vulnerability, please report it privately rather
than opening a public issue. This gives maintainers time to address it before it
is publicly disclosed.

Please include:

- A clear description of the issue and its impact
- Steps to reproduce, or a proof of concept if possible
- The affected versions or commit range
- Any suggested mitigations

Reports can be sent to the project maintainers via a private channel such as
GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
if enabled on this repository, or to the maintainer contact listed in the
repository.

## What to expect

- We will acknowledge receipt as soon as possible.
- We will investigate and keep you informed of progress.
- Once resolved, we will coordinate a disclosure timeline with you.

Please do not exploit, exfiltrate, or otherwise act on a vulnerability beyond
the minimum needed to demonstrate it responsibly.
