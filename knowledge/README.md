# knowledge/

This folder is the project's **knowledge base** — a home for durable,
cross-cutting project knowledge that is not tied to a single feature or route.

It serves as a reference for both humans and AI agents working on the project.

Suggested contents:

- `plan.md` — project plan / roadmap
- `changelog.md` — notable changes over time
- `decision-log.md` — recorded decisions and their rationale (ADRs)

Keeping these here (rather than scattering them) makes the knowledge base
coherent and easy to navigate.
